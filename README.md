## Installation

Install bun.js on MacOs or Linux

```bash
  curl -fsSL https://bun.com/install | bash
```

Install bun.js on Windows

```bash
  powershell -c "irm bun.sh/install.ps1|iex"
```

Install bun.js with NPM

```bash
  npm install -g bun
# the last `npm` command you'll ever need
```

## Execution

```bash
  bun start
  bun dev
```
